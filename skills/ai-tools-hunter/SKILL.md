# SKILL: AI Tools Hunter

Discover new free/freemium AI tools relevant to business.

## What It Does

Search for new AI tools, test basic features, log findings.

## Inputs

- None (web search)

## Outputs

- ai_tools_discovery.json
- List: tool name, category, free tier, link

## Steps

1. Search for new AI tools (ProductHunt, HackerNews, Twitter)
2. Filter for free/freemium + business-relevant
3. Test if possible
4. Log to JSON with date discovered

## Categories

- Email automation
- Design (Canva alternatives)
- Content generation
- Market research
- Customer management

## Notes

Update daily 6:00 AM before syncing to H.
