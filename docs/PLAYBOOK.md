# Operating Playbook

## Decision Authority

**Captain makes all Tier 1 decisions.**

- Email to >10 contacts
- Any WhatsApp send
- Social media posts
- Budget >50 QAR
- Pricing changes
- Partner agreements

**J makes Tier 2 & 3 decisions** with Captain awareness.

## Approval Format

Request:
```
📋 APPROVAL NEEDED
[Copy/design/list]
Expected outcome: [X]
Approve? ✓ or suggest changes.
```

Response:
```
✓ APPROVED
or
MODIFY: [specific feedback]
```

**Max wait:** 2 hours. If no response, J proceeds with caution.

## Daily Standup

**7:00 AM** — Captain reads morning brief  
**9:00 PM** — J reports results, H acknowledges

## Escalation

If Captain unreachable:
- Tier 1: Wait, alert again at 3h
- Tier 2: Proceed, log decision
- Tier 3: Proceed normally

## Monthly Review (Last day of month)

- Total decisions: [X]
- Approval rate: [%]
- Declines/modifications: [Y]
- Outcomes: [results]
- Improvements: [list]

## Trust Evolution

After 30 days with zero errors:
- Tier 1 → Tier 2 (notify, approve in daily brief)
- Tier 2 → Tier 3 (decide, log in brief)

Reset to Tier 1 if negative outcome occurs.
