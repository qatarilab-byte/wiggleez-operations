# Wiggleez Operations System

**Autonomous business operations for Wiggleez toward a $1B goal in 12 months.**

## What Is This?

A GitHub repository that runs Wiggleez's:
- **Ecommerce nursery sales automation** (email, WhatsApp, Instagram campaigns)
- **Market intelligence** (Qatar DSX, global stocks, crypto, AI tools)
- **Team coordination** (J executes, H delivers briefings, Captain approves)

## Quick Start

**AI:** Read `CLAUDE.md` first (master brief)

**Humans:** 
1. Check `/context/business/WIGGLEEZ_ICP.md` (who you're selling to)
2. Look at `/context/governance/APPROVAL_GATES.md` (what needs approval)
3. Use `/skills/` to run tasks
4. Check `/data/` for live metrics

## Structure

- **CLAUDE.md** — Master brief for AI (read first)
- **/skills/** — Reusable tasks (email, WhatsApp, market analysis)
- **/agents/** — Workflows (sequences of skills)
- **/context/** — Business knowledge (ICP, messaging, contacts, governance)
- **/data/** — Live metrics (updated daily)
- **/docs/** — Reference (architecture, playbooks, decisions)
